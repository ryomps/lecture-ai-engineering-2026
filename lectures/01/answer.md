LLM（大規模言語モデル）で使われる **temperature（温度）** とは、一言で言うと**「AIの回答の『面白さ・ユニークさ』を調節するつまみ」**のようなものです。

AIは「次に続く確率が最も高い言葉」を予測して文章を作りますが、temperatureの数字を変えることで、その言葉の選び方を変えることができます。

* **温度を「低く」する（0 または 0.1 など）**
  * **AIの状態:** 「超・真面目モード」
  * **動き:** 確率が一番高い、王道で確実な言葉ばかりを選びます。
  * **向いている作業:** プログラミング、翻訳、データの整理、計算など（ミスが許されないとき）。

* **温度を「高く」する（0.8 や 1.0 など）**
  * **AIの状態:** 「クリエイティブ・自由人モード」
  * **動き:** たまには「確率が少し低い意外な言葉」もあえて選ぶようになります。
  * **向いている作業:** アイデア出し、小説の執筆、雑談など（ユニークな回答がほしいとき）。

物理の「温度（熱くすると分子が活発に動き、冷やすとおとなしくなる）」から名前が取られていて、**AIの頭をやわらかくしたり、カタくしたりするための設定値**だとイメージすると分かりやすいです！

LLMを動かすプログラム（Pythonなど）では、APIを使ってAIに指示（リクエスト）を送る際に、設定項目（パラメータ）の一つとして`temperature`を指定します。

一番よく使われる **OpenAI（ChatGPT）のAPI** を例に、具体的なコードを見てみましょう。

### 1. 基本的なコードの書き方

PythonでOpenAIを使う場合、以下のように `temperature` という値をコードに書き込みます。

```python
from openai import OpenAI

# APIの準備
client = OpenAI(api_key="あなたのAPIキー")

# AIに質問を投げる
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "猫について一言で教えて"}
    ],
    temperature=0.7,  # ← ここでtemperatureを指定しています！
)

# AIからの返答を表示
print(response.choices[0].message.content)
```

このコードの `temperature=0.7` の部分の数字を変えるだけで、AIの性格（回答のランダム性）をコントロールできます。

---

### 2. 用途によってコードの数値をどう変えるか？

実際のシステム開発では、アプリの目的によってこの数値を切り替えます。

#### ① 正確さが命のアプリ（例：バグ修正ツール、翻訳アプリ）
間違った答えを出してほしくないので、温度を **`0.0`**（または非常に低い値）にします。

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "以下のPythonコードのバグを直して： [ここにコード]"}],
    temperature=0.0,  # 常に最も確実で正しい答えを出させる
)
```

#### ② 創造性が命のアプリ（例：ブレインストーミング支援、小説の続きを書くAI）
ユニークなアイデアがほしいので、温度を **`0.9`** や **`1.0`** などの高めに設定します。

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "誰も思いつかないような新しいカフェのアイデアを3つ出して"}],
    temperature=0.9,  # 意外性のある面白い単語を選ばせる
)
```

このように、**「AIに何をさせたいか」に合わせてコード内の `temperature` の数値を書き換えて使う**のが一般的です。
